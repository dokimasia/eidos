# Decision log

*Every decision, why we made it, and what would make us reconsider.
The document linked in each row carries the full argument.*

This table lists every settled decision, with one line of reasoning
and, where we recorded one, the event that would make us reconsider.

Look here first. Write a full ADR in [docs/adr/](../adr/README.md)
when that event actually happens, or when the reasoning no longer
fits in one row, and then link the row to it.
[ADR-0001](../adr/0001-use-adrs-for-architecture-decisions.md) says
why we work this way.
