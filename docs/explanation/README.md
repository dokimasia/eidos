# Explanation

These pages explain why eidos works the way it does: where the boundaries
fall, what else was possible, and what the design gives up. Read them away
from the keyboard. Nothing here tells you what to type.

For now the explanation lives in the
[architecture specification](../architecture/README.md), which argues each
mechanism in the document that defines it. The specification addresses
someone building eidos. A page here addresses someone using it, and can
summarise several specification documents in one place.

Do not record decisions here. We edit these pages to keep them current, so
they keep no history of what was decided when. Decisions go in
[ADRs](../adr/README.md), which nobody edits once accepted.
