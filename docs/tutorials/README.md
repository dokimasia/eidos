# Tutorials

A tutorial teaches you eidos by building something that works. You follow it
from the first step to the last and it succeeds. It makes every choice for
you and offers no alternatives.

There are no tutorials yet. The kernel cannot run a workspace from end to
end, so any tutorial written today would fail partway through.

If you already know eidos and want to get something done, read the
[how-to guides](../how-to/README.md).
