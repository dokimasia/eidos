# Research

These pages record what we found out about the world outside this repository,
and cite a source for every claim. ADRs, RFCs and PRDs refer to them by
number.

The specification already rests on findings of this kind. We sequenced the
Kotlin satellite late because its tree-sitter grammar reports a 61%
structural match against the JetBrains PSI reference, and the parser table in
[11-languages.md](../architecture/11-languages.md) picks a parser per
language on similar grounds. Write findings like those up here once they
carry their sources.
