# Requests for comments

Design proposals with the debate attached: motivation, the design in real
interface shapes, the alternatives weighed, and the drawbacks accepted.
Rejected RFCs stay on disk — they are the record of why not.

An RFC precedes code when a change alters a contract shape, has cross-consumer
implications, or has several plausible approaches worth comparing. A settled
single decision is an [ADR](../adr/README.md) instead.
